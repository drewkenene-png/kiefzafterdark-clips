# kiefzafterdark-clips

## Obsidian vault

The `vault/` folder is a ready-to-use Obsidian vault with notes for the Roblox potion shop and the clip pipeline.

**Open it on Windows**

1. Click the green **Code** button on GitHub and choose **Download ZIP**.
2. Unzip it somewhere you'll keep it, like `Documents`.
3. Open Obsidian, click **Open folder as vault**, and pick the `vault` folder inside the unzipped files.
4. Start at the `Home` note.

Daily note: `Ctrl+D`. Insert a template: `Ctrl+T`.
